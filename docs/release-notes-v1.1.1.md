# v1.1.1 · 三网小卡片拖动效果

- 每个运营商的名称、数值和历史条组成一张小卡片，增加淡背景、细边框和圆角。
- 拖起时整张卡片悬浮跟随鼠标或手指，原位保留占位，相邻卡片平滑让位；松手后归位并同步所有节点的延迟、丢包顺序。
- 手机长按拖动、普通滚动、键盘排序与刷新记忆保持不变；取消拖动不会保存新顺序或误打开详情。
- 系统减少动态效果或主题关闭动画时，保留位置反馈并省略过渡。
