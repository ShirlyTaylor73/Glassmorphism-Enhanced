# v1.1.0 · 三网拖动排序

现在可以按自己的习惯调整联通、电信、移动的展示顺序。

- 在任意节点的延迟或丢包面板，拖动运营商整行；松手后所有节点的两个面板同步排序。
- 手机长按后拖动；键盘聚焦运营商行后按 Alt+↑/↓ 调整，Enter/空格查看详情。
- 顺序保存在当前浏览器，刷新保留，不影响其他访客或后台检测任务的顺序。
- 拖出面板、按 Escape 或手势取消时保持原顺序；拖动不会误打开详情。
- 名称、颜色、数值与历史条一起移动，三网识别规则、延迟/丢包计算及中转估算保持不变。

## 安装

下载本 Release 的 komari-theme-Glassmorphism-build-*.zip，在 Komari 后台导入并启用主题。版本按兼容功能升级为 1.1.0，原有设置保留。
