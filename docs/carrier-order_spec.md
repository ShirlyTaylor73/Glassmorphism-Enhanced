# 三网展示顺序拖动（M5）

## 已确认需求

- 用户选择整行拖动，顺序只保存当前浏览器，不写后台配置。
- 任意节点的延迟或丢包面板调整后，所有节点的两个面板使用同一顺序；普通与中转估算一致。
- 名称、颜色、数值、历史条整体排序，不改变任务识别、统计和请求。

## 交互与实现

- 默认联通、电信、移动。共享 store 保存 `theme:carrier-order:v1`，只接受三种 key；去重并补齐缺失项，非法内容回退默认。
- 桌面左键移动至少 6px 开始；触摸长按 350ms 开始，长按前移动超过 8px 取消排序并允许滚动。
- 拖动只在原面板内选择目标行，高亮目标；松手将原行插入目标位置，然后同步所有面板。面板外松手、Escape、pointercancel 或卸载取消，不持久化。
- 普通点击继续打开 Ping 详情，拖动不会触发详情或节点跳转。触摸长按不弹出上下文菜单。
- 每行可聚焦，Alt+上下方向键移动，Enter/Space 打开详情；焦点与数据 key 保持关联，提供操作提示和排序播报。
- 使用现有 Vue/composable/store，不增加依赖；保持原面板尺寸、紧凑布局和颜色。
