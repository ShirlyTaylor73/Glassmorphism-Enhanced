## 动态节点光轨

光轨固定连接两端节点，光头与渐变拖尾沿球面弧线流动，并处理背面遮挡。

- `auto`：自动拓扑，每批最多三条轮播。
- `persistent`：同一自动拓扑固定路径错峰循环，替代原常驻实线。
- `upstream`：保留原上游标签，从上游向下游播放。
- `off`：关闭节点光轨，保留地球装饰。

停止旋转只停止自转；关闭页面动画或启用系统减少动态效果时停止动态效果。配置值和排序偏好保留，无需迁移。自动连线是视觉展示，不代表真实流量。

三网区域同时移除剩余分隔线，保留卡片拖动交互。
