# Glassmorphism Enhanced v1.0.8

## 修复与改进

- 浅色画面显示月亮及“切换为深色主题”；深色画面显示太阳及“切换为浅色主题”。提示和点击结果一致，每次点击都反转实际颜色。
- 普通点击不再混入自动模式，解决连续点击仍停留深色的问题。手动模式旁提供“恢复自动”，恢复跟随后台；北京时间模式为 07:00–19:00 浅色，其他时间深色。
- 默认背景采用 GlassOps 的同一图片、明暗滤镜及移动端定位，不更换卡片或地球样式。
- 保留自定义图片/视频、模糊、遮罩及本地模式选择，加载或失败时使用对应明暗默认背景。

## 升级

上传 ZIP 到 Komari 主题管理并启用 Glassmorphism Enhanced。原有手动主题选择保留，需要自动切换时点击“恢复自动”。不改后台登录、价格权限或三网请求逻辑。

原作者与背景 MIT 来源记录保留。真实生产安装效果需在启用主题后验收；测试视频生命周期使用确定性事件，不代表所有编解码器测试。

## 验证

- 完整 Playwright/visual 125/125，包含 21 项新增明暗、自动恢复、跨时区及媒体回退测试。
- 七张视觉基线经修改前后实际构建对照审核，正式阈值未放宽；lint、type-check、生产构建通过。
