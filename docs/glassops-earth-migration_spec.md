# GlassOps 双地球迁移规格（M4）

## 范围

用户批准以本地 GlassOps c5ba36a 迁移 realistic 实时昼夜/城市灯光/渐变大气层/光晕，以及 cobe 冰青点阵/经纬网/环形轨道/星芒。保持当前首页位置、容器、max-w-md、移动端偏移与球体直径（误差≤5%），不迁移首页排版、后台或 tiled。包含已完成的三网无分隔线修改。本轮不升版本、不 push/release。

## 光轨契约

- 复用 buildEarthArcs：auto 最多24条，分批最多3条轮播；persistent 同一自动拓扑每条错峰循环；upstream 最多48条按标签连接，渲染层反转为上游→下游；off 无节点光轨但保留装饰。
- 保留四个配置枚举，persistent 改为固定路径循环光轨；更新帮助。不叠旧实线，不使用参考项目随机外围起点。
- 共享球面三维路径、稳定 ID 相位、3.2秒光头拖尾飞行；auto 用5秒批次，三条间隔650ms，持续模式间隔650ms。投影适配各渲染器，逐段球体遮挡，保留可见弧段。
- 无效/重复/同坐标过滤沿用现有规则；连接变化移除旧路径，不重启有效连接。不新增API或地理请求。

## 生命周期与降级

停止旋转仅停止自转，光轨保持；系统减少动态效果/主题关闭动画停止自转、光轨、闪烁与粒子，保留静态视觉与手动拖动。隐藏/离屏/KeepAlive离开时暂停；恢复使用当前时间与坐标，不补播。集中更新光轨、不逐条RAF。卸载清理循环/资源/监听器。WebGL或贴图失败显示明确降级，不阻塞首页。

实施前采集旧版两渲染器桌面/移动容器与球心、球体直径基线。根目录test先写纯逻辑失败用例，再实现。新增真实WebGL截图（不得隐藏canvas），覆盖明暗/两尺寸/两渲染器，校验实际像素、端点、遮挡、循环、四模式、停止旋转、减少动画、30/100节点、切换与失败降级。完整test:visual/lint/type-check/build/diff-check通过；仅审核预期变化后更新相关截图。资源哈希/许可证记录，ZIP契约及预览/版本/作者检查。分阶段提交并交付候选包；真机/生产验收另记。
