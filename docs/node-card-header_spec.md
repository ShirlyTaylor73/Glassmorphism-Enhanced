# 首页卡片标题与配色规格

- 用户批准实施，参考本地 GlassOps c5ba36a 的 NodeCard.vue / hasIPv4 / hasIPv6。
- 标题采用两行：左侧国旗（缺失用地球）+名称，下方 OS 图标/系统名/架构；右侧收藏+在线离线，下方 V4/V6 非空字段徽标，双栈并排；不显示真实 IP，不引入请求或未知徽标。
- 保留当前双列指标、三列信息块、在线天数/价格、三网/中转、隐私和所有 card size。长名称/系统截断并提供 title。
- CPU 下方 1/5/15 分钟负载换为 cpu_cores 对应 Xcore；无效/缺失显示 —，不误显示 0core；mini 在 CPU 下补同一核心数。
- 百分比按 GlassOps：CPU violet、内存 rose、硬盘 amber、流量 sky，分别明暗色阶；严重超限沿用告警覆盖，流量既有阈值/计算保留。实时上传 rose、下载 cyan；其他累计流量/三网颜色不改。
- 仅首页卡片，不修改详情、列表、后端与发布版本。补聚焦 UI 测试，检查单栈/双栈/空字段、核心数、长文本、收藏不跳转、各尺寸、明暗配色和隐私；视觉基线仅接受预期标题高度/文本变化。
- 分支 feat/node-card-header，分阶段 commit，生成候选 ZIP；本轮不发布、不替换既有 Release。
