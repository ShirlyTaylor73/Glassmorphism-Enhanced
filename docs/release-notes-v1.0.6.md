# Glassmorphism Enhanced v1.0.6

修复多节点不同续费周期下，月流量查询占满共享请求池、导致三网延迟和丢包长期显示“加载中”的问题。

## 修复内容

- 消除月流量指标与历史查询的重复占位，详情兼容回退不再嵌套申请名额。
- 三网请求优先执行，全局并发仍为 8，月流量在首页和详情合计最多并发 2 个。
- 修复取消后继续回退、Ping 历史 `:tasks` 未取消、旧任务清理同键新任务的问题。
- 保留每台机器独立续费周期、同周期合并、流量缓存、迁移日期、三网算法及现有界面。

## 升级说明

- 从 1.0.5 升级无需新增配置，不修改 Komari Server/Agent 或后端数据。
- 从 1.0.4 或更早版本升级且使用中转规则时，仍需遵循 1.0.5 的格式调整：将 `TargetNode|RelayNode|Task` 改为 `RelayNode|TargetNode|Task`，无自动迁移。
- 本次发布属于 `ShirlyTaylor73/Glassmorphism-Enhanced`；保留原作者与 MIT/第三方许可证署名。

## 验证

- 完整 Playwright/visual 93/93 通过，含 30 节点不同续费日、月流量挂起时三网正常显示的回归；未更换截图基线。
- lint、type-check、生产构建及 ZIP 结构校验通过。既有 globe 大 chunk 提示保留。
- 本地模拟验收不替代真实站点安装后的性能验收。
